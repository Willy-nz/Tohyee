Tohyee

Your Tohyee address

Type the address you open Tohyee at in a browser. The app opens your own Tohyee server there, with your usual sign-in.

It starts with https://. You can leave that off.

Where do I find my Tohyee address?
  • It's the address in the browser when you use Tohyee, for example https://tohyee.example.nz.
  • Whoever looks after Tohyee can find it in Server settings › Remote access (a Tohyee web address, or your own Cloudflare tunnel).
  • Tailscale: an https://….ts.net address, with the Tailscale app on and connected on this phone.
  • A home-network address like http://192.168.1.20:3000 doesn't work in the app: it isn't HTTPS. Use one of the above.

The app only opens this address. Links to other websites open in the phone's browser.
