A few useful details

Before you get started.

Do I need to be a farmer?

No. Accounting, CRM, analytics, payroll and jobs work for other businesses too. Farming is a separate part of the workspace.

Can my team use it away from the server?

Yes, with remote access configured. Use HTTPS and follow the setup guide. You control accounts and permissions; self-hosting still needs updates, backups and secure access.

Does it work on a phone?

The web app works in a browser, with installation options depending on your device. Selected farm workflows support offline use. An optional Android APK adds device features; it is not an iPhone app. See the mobile guide for current limits.

How does AI access work?

Connect a compatible AI app from Tohyee’s AI settings. You choose the organisation and access level. Depending on that level, AI can read data, create drafts or post changes—read-only access is available.

What's included in the latest release?

The release notes and downloads describe each packaged release. The feature register covers current source, limitations and work in progress.
