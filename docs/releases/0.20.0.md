## Before you update

- **The database updates itself when Tohyee starts** (tenant migration 0209).
- **The Android app isn't signed yet.** Until the signing key is added to GitHub (see `docs/MOBILE-APP.md`), this release's APK is a test build that installs as "Tohyee (test)". Keep the signing key safe once it's made: every later version must use the same key, or phones can't update.
- **Not yet tried for real:** the Android app on a real phone (it was only opened on an emulator), locked-screen tractor recording, phone reminders, and AI cover estimates from real photos.
- **Not yet reviewed by Jess:** decisions 1140–1152 (Android) and 1160–1169 (pasture photos), including the app ID `io.github.willy_nz.tohyee`, which can't change once it's on the Play Store.

## New

- **Tohyee for Android:** download `Tohyee-0.20.0.apk` from this release, or from "Get Tohyee on this device", and allow installs from that source. The first time, type your Tohyee address. It checks it's a Tohyee server over HTTPS, remembers it, and opens your server inside the app.
  - **Tractor mode keeps recording with the screen locked,** with Android's "Tohyee is recording a tractor job" notification. It asks for permission only when you start a job.
  - **Reminders on the phone,** off until you turn them on: shift the pods or irrigator, read the pond, effluent checks and servicing, your safety actions, and the LINZ key running out.
  - **The phone's own camera and photo picker** for Safety, Effluent, faults and paddock photos, keeping the time and GPS.
  - The web app and browsers work as before.
- **Paddock photos and covers from photos:**
  - add photos to a cover reading, a farm walk or a paddock card;
  - each paddock has a photo diary beside its readings, marked Measured or Estimate.
  - **Your own connected AI can suggest a cover from a photo.** You need Claude or ChatGPT connected at "Make drafts". It shows "AI estimate from a photo, not measured" until you accept, change, keep it for comparison or decline it. It never replaces a measured reading.
  - **Pasture and feed shows how far photo estimates usually are** from measured readings in the same paddock within a couple of days. It never adjusts anything.
  - Pasture.io isn't connected yet; a Pasture.io export file can be imported.
