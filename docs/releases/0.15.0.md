Everything merged since 0.14.0 (#435, #442, #443 and #448).

## Before you update

- **Security: update soon.** Next.js, which Tohyee runs on, is updated to 16.4.1. It fixes two critical problems that could let someone run their own code on a server, and one that could crash it (#435).
- **The database updates itself when Tohyee starts** (core migrations 0021 and 0022).
- **Old-style backups can't be opened any more.** Only backups made with the recovery key (since 0.12.0) restore. Older backup files are left alone, never deleted (decisions 867–869).
- **The demo farm has moved** from the organisation menu in the books to the server's Organisations page (decisions 880–884).

## New

- **Invite people from People and roles:** owners and admins invite someone by name, email and role. If they're new, Tohyee makes their login and emails them a setup link, where they choose a password or Sign in with Google. Until they sign in they show as Invited, with Resend and Cancel. A new login only opens that organisation. Only owners can invite owners (decisions 870–879).

## Changed

- **Demo farm:** server admins add it from the Windows server app's Organisations page, or the Organisations page in the browser's server settings, for themselves or another login, and reset or delete it there. A demo farm that already exists still opens from the organisation menu with its DEMO badge.
- **Backups:** only the recovery key and recovery kit; the older backup key and its screens are gone.
