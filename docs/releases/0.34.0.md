## Before you update

- **The database updates itself when Tohyee starts.** This release adds tenant migrations 0276 and 0277.
- **Not yet reviewed:** the worked examples for modelled pasture cover and farm weather are Claude's, not yet checked. Neither has been tried against real plate-meter readings or MetService's live service.
- **Daily farm weather uses MetService API units:** once a day, 5 days of rain and temperature for each pinned farm. It only runs if you keep MetService records and allow combining them with farm data (Settings › Weather).

## New

- **Modelled pasture cover from satellite greenness (optional):** each farm's own plate-meter readings are paired with clear satellite pictures of the same paddock. The line is checked on dates it wasn't fitted on, by season, and against your other farms. An owner or admin chooses the average error they'll accept, and estimates turn on only if the check met it. Estimates are shown as "Modelled cover" with a range. They're never saved as readings or used for planning (#669).
- **Daily rain and temperature for each farm from MetService:** worked out from the forecasts Tohyee keeps, plus MetService's last 5 days of history. Shown on Farm › Rainfall. A rain gauge reading wins where there is one (#670).
- **Rain in modelled cover:** the cover check also tries the rain (and temperature) from the 14 days before each picture, and uses it only if it makes the estimates closer (#670).

## Fixed
