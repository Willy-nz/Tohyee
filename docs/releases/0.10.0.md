Changes on main since 0.9.0 (not released yet).

## Changed

- **Remote access pauses itself when someone is guessing passwords:** 20 failed sign-ins through remote access within 10 minutes pause signing in from outside for an hour (longer if it happens again the same day), and server admins are emailed. The local network keeps working, and customers' payment and form links aren't affected. Resume early under Remote access on the server computer (decision 542).
- **Two-step sign-in after a changed server key:** if the server's secret key changes so an authenticator key can't be read, the password alone no longer lets someone set up a new authenticator. Use a backup code, the emailed reset link, or ask a server admin to reset two-step on the server computer. Putting the right key back makes the old authenticator work again (decision 543).
