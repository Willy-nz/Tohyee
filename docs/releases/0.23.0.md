## Before you update

- **The database updates itself when Tohyee starts** (tenant migrations 0212 and 0213).
- **Not yet tried for real:** the security cameras and the camera post box have not been tried with a real Reolink camera, over 4G, or on a real rented server. The post box install script has only been checked, not run on a fresh server. See `docs/FARM-SECURITY.md` for what's verified and what isn't.
- **Camera post box:** after updating, Farm › Security › Post box shows the install command for this version. You need a small rented Ubuntu server with a public IPv4 address, with TCP ports 21, 50000–50019 and 8443 open in the provider's firewall.

## New

- **Farm security cameras (Farm › More › Security):** add Reolink cameras per farm; each gets its own upload login to type into the Reolink app. Photos and clips arrive as events you can browse by farm and camera, play and download. Each event says "Photo only" or "Clip saved", and a camera that has gone quiet is flagged ("No uploads from Back road since Friday"). Keep an incident with a note so it's never cleaned up; everything else is removed after 30 days (changeable per farm). Only owners and admins see cameras until you give others access on People and roles; downloads, deletes and setup changes are audited. Every Security screen reminds you cameras record staff and visitors (#525).
- **Camera post box:** 4G cameras can't reach a server at home, so they upload to a small rented server instead, and Tohyee collects from it every minute. Nothing at home is opened up. Files waiting there are locked with a key only Tohyee holds, and are deleted only after Tohyee has saved them. Five short steps on Farm › Security › Post box take you through it (#526).
- **Short help with an (i):** 129 long paragraphs across 74 screens are now one short line, with the rest behind an (i) you tap. Warnings, things you can't undo and "who can see this" notices are still shown in full (#522).
- **Pictures across the whole app:** every module's headings and menus now have drawn icons, including Accounting, CRM, Analytics, Farm and Settings (#520).

## Changed

- **(i) buttons** show a clear outline when you reach them with the keyboard, and their popups always fit on screen, including on a zoomed-in phone (#524).

## Not in this release

- Fetching clips from a camera's SD card on request, AI tags on camera footage, and live view.
