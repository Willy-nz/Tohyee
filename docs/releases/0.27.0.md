Everything merged since 0.26.0 (#566, #567, #568, #569, #580, #581 and #582).

## Before you update

- **The database updates itself when Tohyee starts** (tenant migration 0226, which corrects Shopify payout settlements stored before 0.26.0).
- **Shopify, after updating:**
  1. Settings › Sales platforms › your store: if it says **Needs reconnecting**, click **Reconnect** and enter your Shopify app's client ID and secret. Reconnect now reuses the same connection instead of making a second one.
  2. Click **Sync now**. Payouts refused before are read again and post, so Shopify clearing clears.
- **AI apps:** reconnect Tohyee in your AI app after updating. Tool answers have a new, consistent shape (see Changed), the AI no longer asks before every step, and it only sees tools for modules you've turned on.
- **Not yet tried for real:** the payout and reconnect fixes were tested with made-up Shopify-shaped data only.

## New

- **Oldest month first:** compared periods on the Profit and loss and Balance sheet run oldest on the left to newest on the right, with Total and Year to date at the far right. An **Order** choice switches back, and each report remembers it in your browser (#566).
- **Reconnect a store:** when Shopify rejects Tohyee's login, the store card says **Needs reconnecting** with a Reconnect button, and its status shows the last successful sync (#581).
- **GST return for an unregistered period:** says "Not registered for GST for this period" instead of showing a return of zeros; a period that straddles the registration date says which days count. Filing an unregistered period is refused (#582).
- **New website:** a redesigned public site with current screenshots of the app (#569).

## Changed

- **Shopify payouts are listed once:** a store connected twice no longer shows every payout twice or doubles the clearing balance (#581).
- **Bank suggestions:** voided journals and their reversals are no longer suggested (a **Show voided** button still lists them). Suggestions are ranked by closest amount, and a line that is a Shopify payout shows it (#581).
- **Farm menu:** Security is in the Farm **More** menu (#567).
- **AI goes ahead with what you asked:** it no longer asks before every step; Tohyee's own checks are unchanged (#568).
- **AI tools for your modules only:** an organisation without Farming doesn't see farm tools, and so on; turning a module on tells the AI app (#582).
- **Consistent AI answers:** every list pages the same way (cursor, nextCursor, more); accounts can be given by id or code and list_accounts returns ids; the Profit and loss, Budget vs actual and custom report tools share one columns-and-rows shape with the screen's labels; times are ISO 8601; clearer reason codes, and no customer emails in problem messages (#580, #581).
- **Budget vs actual** uses the same section names as the Profit and loss ("Trading income", "Operating expenses") (#580).
