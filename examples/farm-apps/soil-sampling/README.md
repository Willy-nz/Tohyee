# Soil sampler (sample farm app)

A one-file web app for Tohyee's Farming API: see paddocks by their last
soil test, record samples in the field with the phone's location, and see
them in Tohyee under Soil tests. Open `index.html` in a browser or put it on
any web host. It needs an app key made under Farm › Farm apps with read
farms, read soil and record soil samples. See [docs/FARM-APPS.md](../../../docs/FARM-APPS.md).
